# 🥊 FIGHTLAB

### MMA & Boxing Training + Fight Analysis Platform

FIGHTLAB is a simple full-stack web application designed for boxing and MMA enthusiasts. It combines training resources, technique learning, Fight IQ testing, fight analysis, and a training assistant in one platform.

---

## 🚀 Features

- 🔐 User Signup & Login
- 🥊 Boxing & MMA Technique Library
- 🎥 Training Videos
- 🧠 Fight IQ Quiz
- 📊 Fight Analysis
- 💬 Training Assistant
- 🥋 Fighting Legends
- 📋 Personal Dashboard
- 💾 SQLite Database
- 🌐 Full-Stack Web Application
