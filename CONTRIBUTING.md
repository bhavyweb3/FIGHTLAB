FIGHTLAB is a student-developed full-stack web application focused on **Boxing and MMA training, technique learning, Fight IQ, fight analysis, and training resources**.

We welcome contributions that improve the project, fix bugs, improve the user experience, add useful training features, or improve the documentation.

# 🥊 About FIGHTLAB

**FIGHTLAB** is an MMA and Boxing training and analysis platform designed to bring different aspects of combat sports learning into one simple web application.

The project includes features such as:

- User registration and login
- Personal dashboard
- Boxing and MMA techniques
- Training videos
- Fight IQ quiz
- Fight analysis
- Training assistant
- Fighting legends section
- Database integration
- Backend APIs
- Session-based authentication

The project is built using a simple full-stack architecture so that the code remains understandable and easy to maintain.
